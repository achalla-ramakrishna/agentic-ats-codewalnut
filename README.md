# CodeWalnut ATS

Applicant tracking system for CodeWalnut — one place to run every hire
from requisition to signed offer.

Stack: Spring Boot 3 (Java 21) + React/TypeScript (Vite) + MySQL — same as
`agentic-pr-reviewer`. Status: **spec stage**, no application code yet.

- [`docs/SPEC.md`](docs/SPEC.md) — requirements, workflow, acceptance criteria, chunk plan, open questions
- [`docs/architecture.md`](docs/architecture.md) — architecture, modules, data model, integrations
- [`docs/adr/`](docs/adr/) — architecture decision records
- [`AGENTS.md`](AGENTS.md) — house rules for humans and coding agents
