# How to do things in the CodeWalnut ATS

Menu (left side; people see only what their role allows): Dashboard, Ask ATS, Openings, Candidates,
Messages, Clients, Interviews, Interview questions, Tests, Admin updates, Users, View as, Audit log,
What's new.

Stages, in order: Applied / Sourced, Screening, Interviewed, Shortlisted, Submitted to client,
Client interview, Selected, Offer sent, Offer accepted, Joined. Off the main path: On hold, Rejected,
Withdrawn.

## Openings
- New opening: Openings → New opening.
- Rename an opening, change its client, hiring type or people needed: open the opening → Edit opening.
- Job description, location, work mode and the public apply link: open the opening → Job details &
  share link → turn the link on → Copy link. Applicants arrive at Applied / Sourced with their résumé.
- Interview kit from the job description: open the opening → Interview kit → Generate interview kit.
  It suggests a test, interview questions per round, coding problems and a scorecard.

## Candidates
- Add one: open the opening → Add candidate. Many: Import, then paste a table from Excel or Google
  Sheets (name, email, phone).
- Upload résumés: open the opening → Upload résumés (needs a job description for the match score).
  The AI fills each profile and a Match %; "AI suggestions" shows who to contact next.
- Open a candidate: click their name in an opening (or search in Candidates). The panel has Profile,
  Chat with candidate, Team chat, history and documents.
- Move a stage: open the candidate → choose the new stage (rejections need a reason). Or type an
  instruction in the opening's search box ("move Asha and Ravi to shortlisted") → ✨ Ask AI → Apply.
- Add a note: open the candidate → add a note.
- Put a candidate forward for another client: open the candidate → Openings → Add to another opening.
- Search inside an opening: the search box above the stage buttons (press /). Questions like "who
  knows React?" → ✨ Ask AI.

## Clients
- Add a client: Clients → New client. Rename: Clients → Rename.
- Client contacts sign in with their own email: Clients → add a contact.
- Share a candidate with a client: open the candidate → Profile → Share with <client> → choose what
  to share (contact details, profile, documents) → Share. You can stop sharing any time.
- CodeWalnut résumé (client-ready PDF in CodeWalnut's template, phone number removed, email shown):
  open the candidate → Profile → CodeWalnut résumé → ✨ Create with AI → Edit and check → Preview
  PDF → Save PDF to documents, then Share with the client.

## Interviews
- Schedule (Google Calendar + Meet invite): open the candidate → Schedule interview. Connect Google
  the first time.
- Reschedule or cancel: open the candidate → Interviews → Reschedule / Cancel. The Meet link stays.
- Interview held elsewhere: open the candidate → Log an interview held elsewhere.
- Upcoming and recent interviews: Interviews in the menu. "Waiting for your feedback" lists what you
  owe.
- Feedback form: Interviews → Give feedback (or the candidate's Interviews → Feedback form). It saves
  a private draft while you type; choose a recommendation and Submit. Other panel members' feedback
  shows after you submit yours.
- Live coding room: on the interview's feedback page → Coding room → pick a problem → Open coding
  room → Copy link into the Meet chat. You watch their code live, can Run it, give the Next problem
  and End room.
- Interview questions: Interview questions in the menu → pick role and level → Pick the ones to ask.

## Tests
- Make a test: Tests → Build from bank (by role and level, by topics, coding) or New test (✨ AI
  draft or your own questions) → check → Mark ready.
- Send: open the candidate → Profile → Tests → Send test (email and/or WhatsApp), or Tests → open
  the test → Send to candidates (many at once). Copy link to share it yourself.
- Results: Tests → New test results; the candidate's Tests tab shows answers and scores; Remind if
  they haven't started.

## Messages
- Email or WhatsApp a candidate: open the candidate → Chat with candidate → write or pick a
  template → tick Email and/or WhatsApp → Send.
- Team chat about a candidate: open the candidate → Team chat.
- Messages in the menu shows conversations waiting for a reply.

## Background verification
- Open the candidate → Profile → Background verification → Request from candidate → tick the
  documents. The candidate uploads them on their candidate page. Aadhaar and PAN are visible only to
  Admins, Recruiters and Account Managers.

## Admin
- Users and roles: Users (Admins only). Add the person's @codewalnut.com email and roles; they sign
  in with Google. If Google sign-in is refused, the login page says which email was refused and why.
- Admin updates: summaries of submitted feedback and key stage changes (shortlisted, selected, offer
  accepted, joined).
- View as: see the app as a role, a client contact or a candidate (read-only).
- Audit log: who did what and when.
