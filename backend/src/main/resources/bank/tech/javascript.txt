@topic js-dom | FUNDAMENTALS | The DOM and events | Selecting elements, changing content, event listeners, bubbling and delegation, preventDefault, forms.
Q E Which method selects the first element matching a CSS selector?
+ document.querySelector(".card")
- document.getElement(".card")
- document.find(".card")
- document.select(".card")
= querySelectorAll returns all matches.

Q E Which method adds a click handler to a button element btn?
+ btn.addEventListener("click", handler)
- btn.attachHandler("click", handler)
- btn.listen("click", handler, true)
- btn.onClick = handler.bind(btn)()
= addEventListener can attach several handlers to the same event.

Q E Which property safely sets plain text inside an element?
+ textContent
- innerHTML
- outerHTML
- value
= textContent never interprets HTML, which avoids injecting markup.

Q E What does event.preventDefault() do on a form's submit event?
+ Stops the browser submitting the form and reloading the page
- Stops every other event listener on the page from running
- Clears all the form's fields so it can be filled again
- Removes the submit listener after it has run once
= Use it when you handle submission with JavaScript (e.g. fetch).

Q M What is event bubbling?
+ An event on a child also fires on its ancestors, moving up the tree
- Events fire in a random order across elements on the page
- An event fires only on the document, never on the element
- Events wait in a queue until the whole page has loaded
= stopPropagation() stops the event moving up.

Q M What is event delegation?
+ One listener on a parent that checks event.target, instead of one per child
- Sending every DOM event to the server to be handled there instead
- Handling events in a web worker so the main thread stays free
- Cancelling events on children so only the parent's listener runs
= It works for children added later and uses fewer listeners.

Q M When does the DOMContentLoaded event fire?
+ When the HTML is parsed into the DOM, before images finish loading
- After every image, stylesheet and script on the page has loaded
- When the user first clicks or types anywhere on the page
- When the user closes the tab or navigates to another page
= The load event waits for images and other resources.

Q M Why is setting innerHTML with user input dangerous?
+ It can run injected scripts (cross-site scripting)
- It is slower than textContent for long strings
- It removes every event listener on the page
- It only works in older versions of browsers
= Use textContent, or sanitise HTML before inserting it.

Q H What is the difference between event.target and event.currentTarget?
+ target started the event; currentTarget is where the listener runs
- They always refer to the same element in every situation
- currentTarget is always the direct parent of target
- target is always the window object for bubbling events
= With delegation, currentTarget is the parent and target the clicked child.

Q H Why can reading offsetHeight right after changing styles in a loop be slow?
+ Each read forces a fresh layout calculation (layout thrashing)
- offsetHeight is no longer supported by modern browsers
- Reading it blocks network requests until layout finishes
- Reading it reloads the page's stylesheets every time
= Batch reads first and writes after, or use requestAnimationFrame.

Q H What does the third argument { passive: true } in addEventListener mean?
+ The handler won't call preventDefault, so scrolling stays smooth
- The handler runs only once and is then removed automatically
- The handler runs during the capture phase instead of bubbling
- The handler is skipped whenever the page is scrolling
= Browsers can scroll without waiting for the handler.

Q H Which is the most efficient way to add 1,000 list items to the page?
+ Build them in a DocumentFragment and append it once
- Append each item to the live list, one at a time
- Reload the page after adding each group of items
- Call document.write once for each new item
= One insertion triggers one layout instead of a thousand.

= Split long work into chunks or move it to a Web Worker.

Q E Which queue do promise callbacks (then/catch) go into?
+ The microtask queue
- The timer queue
- The rendering queue
- They run synchronously
= Microtasks run as soon as the current task finishes, before timers.

- A C D B

Q M What does requestAnimationFrame do?
+ Runs a callback just before the next repaint

- Pauses rendering until the callback has finished
- Runs the callback in a separate web worker thread

Q M In Node.js, when does a setImmediate callback run?

Q H What can happen if a microtask keeps queueing new microtasks forever?

- Each microtask is moved to a new thread to keep up

Q H Why can a CPU-heavy function hurt a Node.js server more than a slow database query?

- Node.js cannot run CPU code at all, so the request fails
- It uses more memory, which slows the garbage collector down

@topic js-performance-security | ADVANCED | Performance and web security | Debounce and throttle, memory leaks, lazy loading and bundles, Core Web Vitals, XSS, CSRF, CORS, CSP, storing tokens.
Q E What does debouncing a search box handler do?
+ Waits for a pause in typing before running the search
- Runs the search on every single key press
- Blocks typing until the last search has finished
- Runs the search once a day in the background
= It avoids sending a request for every character.

Q E What is cross-site scripting (XSS)?
+ An attacker's script runs in other users' browsers on your site
- A network request that takes too long and times out
- A CSS layout bug that hides content from some users
- A database deadlock caused by two users saving at once
= Escape output and avoid inserting untrusted HTML.

Q E What does lazy loading images do?
+ Loads images only as they are about to come into view
- Loads every image twice to make sure it arrives
- Shows a blurred version of every image permanently
- Removes images from the page to save bandwidth
= Use loading="lazy" on img tags below the fold.

Q E What does HTTPS protect?
+ Data travelling between browser and server, from eavesdropping and tampering
- Data stored in your database, from anyone who steals the disk
- Your application, from bugs that would expose user data
- User accounts, from attackers guessing weak passwords
= It encrypts traffic and proves the server's identity.

Q M What is the difference between debounce and throttle?
+ Debounce waits for a pause; throttle runs at most once per time window
- They are the same
- Throttle waits for a pause; debounce runs once per window
- Debounce is for clicks only
= Throttle suits scroll handlers; debounce suits search inputs.

Q M What does CORS control?
+ Which other origins browsers let read your API's responses
- Whether your server is allowed to make outgoing requests
- How cookies are encrypted before being sent to the server
- How quickly responses are delivered to other origins
= CORS is enforced by browsers, not a security boundary against servers or curl.

Q M What is CSRF?
+ Another site makes the user's browser send an authenticated request to yours
- A script on another site reads your site's cookies directly from the browser
- An attacker types SQL into a form field to change your database queries
- A flood of requests from many computers overloads your server
= Defences: SameSite cookies, CSRF tokens, and checking the Origin header.

Q M What is code splitting in a front-end build?
+ Loading only the code a page needs and fetching the rest on demand
- Writing the application's code across many separate source files
- Shortening variable names so the bundle downloads faster
- Running the application's code on two threads at the same time
= Dynamic import() creates separate chunks.

Q H Why is storing a long-lived auth token in localStorage risky?
+ Any script injected through XSS can read and steal it
- localStorage is cleared automatically every minute
- localStorage is sent with every request automatically
- localStorage cannot hold strings as long as a token
= An HttpOnly, Secure, SameSite cookie cannot be read by JavaScript.

Q H What does a Content Security Policy (CSP) header do?
+ Tells the browser which sources of scripts and other content are allowed
- Encrypts the page so only the intended user can read it
- Compresses responses so pages download faster
- Blocks all cookies from being set by the page
= A strict CSP makes injected inline scripts fail to run.

Q H Which is a common front-end memory leak?
+ Listeners or intervals that are never removed when a component goes away
- Using const instead of let for variables that never change
- Using arrow functions instead of regular functions for callbacks
- Declaring more CSS classes than the page actually uses
= Clean up in teardown code (e.g. a React effect's cleanup function).

Q H What does Largest Contentful Paint (LCP) measure?
+ How long the largest visible content takes to render
- How long until the user can first scroll the page
- How large the JavaScript bundle is, in kilobytes
- How many HTTP requests the page makes while loading
= Good LCP is under 2.5 seconds; it is one of Google's Core Web Vitals.
