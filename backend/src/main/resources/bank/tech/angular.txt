@topic ng-components | FUNDAMENTALS | Components and templates | Components, templates and styles, interpolation, standalone components, lifecycle hooks, the Angular CLI.
Q E What does the @Component decorator define?
+ The selector, template and styles of a component
- The routes and guards of a feature module
- The HTTP endpoints a service will call
- The database entities used by the app
= Each component pairs a TypeScript class with a template.

Q E How do you show a component property title in its template?
+ {{ title }}
- ${title}
- <%= title %>
- [[ title ]]
= Double curly braces are interpolation.

Q E Which CLI command creates a new component?
+ ng generate component user-card
- npm create component user-card
- ng new component user-card
- ng add component user-card
= The short form is ng g c user-card. ng new creates a whole workspace; ng add installs libraries.

Q E What is a standalone component?
+ A component that lists its own imports instead of being declared in an NgModule
- A component that has no inputs and cannot receive data
- A component that is rendered only on the server
- A component that cannot be used inside other components
= Standalone is the default for new projects since Angular 17.

Q M Which lifecycle hook is the usual place to load initial data?
+ ngOnInit
- constructor
- ngAfterViewChecked
- ngDoCheck
= Inputs are set by ngOnInit; keep constructors for dependency injection. ngDoCheck and ngAfterViewChecked run on every check.

Q M When does ngOnChanges run?
+ When a bound @Input value changes, including before ngOnInit
- After every change detection pass, whether or not inputs changed
- Only once, after the component's view has been created
- When any property of the component class is reassigned
= It receives a SimpleChanges object with previous and current values.

Q M What does ngOnDestroy help you do?
+ Release subscriptions, timers and listeners
- Reset the component's inputs to their defaults
- Re-create the component with fresh state
- Save the component's state to local storage
= Leaks happen when subscriptions outlive their component.

Q M How are a component's styles scoped by default?
+ To that component's own template
- To the whole application, like a global stylesheet
- To the component and every component nested inside it
- To the component's host element only, not its template
= Angular's emulated encapsulation adds attributes to scope the CSS.

Q H Why might reading a @ViewChild element in ngOnInit give undefined?
+ The view is not built yet; read it in ngAfterViewInit
- ViewChild queries only find elements inside ng-content
- ViewChild only works on components, never on HTML elements
- The element must also be declared in the component's providers
= Child views are created after ngOnInit (unless the query is { static: true } on static content).

Q H What is content projection?
| <app-card><h2>Title</h2></app-card>
+ Showing markup passed by the parent where the child places <ng-content>
- Copying the child's template into the parent at build time
- Rendering the child component in a separate browser window
- Passing the h2 element to the child as an @Input value
= Multiple slots use <ng-content select="...">.

Q H What do signal inputs (input()) give over @Input()?
| name = input.required<string>();
+ A read-only signal, read as name(), usable in computed()
- A writable property that also updates the parent automatically
- An observable that must be subscribed to in ngOnInit
- A value that is set once and never changes afterwards
= Available since Angular 17.1. Two-way binding uses model() instead.

Q H What does inject() do inside a component class field?
| private api = inject(ApiService);
+ Gets ApiService from the injector, like constructor injection
- Creates a new ApiService instance each time the field is read
- Lazy-loads the module that contains ApiService on first use
- Registers ApiService as a provider for child components
= inject() works in fields, constructors and factory functions run in an injection context.

@topic ng-binding | FUNDAMENTALS | Data binding and component communication | Property binding, event binding, two-way binding, @Input and @Output, EventEmitter, template reference variables.
Q E Which syntax binds a value to an element's property?
+ [disabled]="isSaving"
- (disabled)="isSaving"
- {disabled}="isSaving"
- #disabled="isSaving"
= Square brackets bind a value from the component to the element.

Q E Which syntax handles a click event?
+ (click)="save()"
- [click]="save()"
- {click}="save()"
- #click="save()"
= Parentheses bind events from the element to the component.

Q E What does [(ngModel)]="name" do?
+ Shows name in the input and updates name as the user types
- Copies name into the input once, when the page loads
- Updates name as the user types, but never shows its value
- Validates that name is not empty before the form submits
= The "banana in a box" combines property and event binding (needs FormsModule).

Q E How does a parent pass data into a child component?
+ Through the child's @Input, e.g. [user]="selected"
- Through the child's @Output, e.g. (user)="selected"
- By setting a global variable the child reads
- By adding the data to the child's providers array
= @Output and events send data back up.

Q M How does a child notify its parent of something?
| @Output() saved = new EventEmitter<string>();
+ this.saved.emit(value), handled by (saved)="onSaved($event)"
- this.saved.next(value), read by the parent through @ViewChild
- this.saved = value, which the parent sees through [saved]
- this.parent.onSaved(value), using an injected parent reference
= $event holds the emitted value.

Q M What is a template reference variable?
| <input #email /> <button (click)="send(email.value)">Send</button>
+ A name (#email) for an element, usable elsewhere in that template
- A component property that Angular creates for every input
- A CSS id that Angular adds to the element at run time
- A route parameter read from the URL by the template
= It avoids extra component properties for simple cases.

Q M What is the difference between [value]="x" and value="{{ x }}"?
+ Interpolation always turns the value into a string
- Interpolation is two-way; property binding is one-way
- Property binding runs once; interpolation updates live
- Interpolation works on components, property binding does not
= Property binding can pass objects, booleans and numbers as they are.

Q M How do you add a CSS class only when isActive is true?
+ [class.active]="isActive"
- (class.active)="isActive"
- class="{{ active: isActive }}"
- [active.class]="isActive"
= [ngClass] binds several classes at once.

Q H What does model() (Angular 17.2+) create?
| value = model(0);
+ A signal input that supports [(value)] two-way binding
- A read-only signal input that the child cannot change
- A form control with built-in validation for the value
- A store slice that is shared across the application
= Writing value.set(...) in the child updates the parent's bound signal.

Q H Why can binding {{ total() }} to a plain method in a template hurt performance?
+ The method runs on every change detection pass
- The method's result is cached and never updates
- The method is moved to a web worker and runs late
- The template stops detecting changes until reload
= Use a signal, a pure pipe or a precomputed property instead.

Q H How do sibling components share data cleanly?
+ Through a shared service or their common parent
- By reading each other's fields through @ViewChild
- By writing the data to localStorage on every change
- By each keeping its own copy and syncing on input
= A service holding a signal or observable acts as the single source of truth.

Q H What does output() (Angular 17.3+) replace?
| saved = output<string>();
+ @Output() with an EventEmitter
- @Input() with a setter method
- @ViewChild() with a static query
- @HostListener() with an event name
= Call this.saved.emit(value) as before, with a simpler typed API.

@topic ng-directives-pipes | FUNDAMENTALS | Control flow, directives and pipes | @if, @for and @switch, structural vs attribute directives, ngClass and ngStyle, built-in and custom pipes.

- @when isLoggedIn { <p>Welcome</p> }
- #if (isLoggedIn) { <p>Welcome</p> }

Q E What does a pipe do in a template?
+ Formats a value for display, e.g. as currency
- Sends the value to the server for saving
- Creates a new component from the value
- Checks the value against a form validator
= Built-in pipes include date, currency, uppercase, json and async.

Q E Which loops over a list in Angular 17+ templates?
+ @for (job of jobs; track job.id) { ... }
- @for (job in jobs; key job.id) { ... }
- @each (job of jobs; by job.id) { ... }
- @loop (job of jobs; track job.id) { ... }
= track is required in @for.

Q E What does {{ today | date:'dd/MM/yyyy' }} show for 3 October 2026?
+ 03/10/2026
- 10/03/2026
- 2026-10-03
- 3 Oct 2026
= The format string decides the order: day, month, year.

Q M What is the difference between structural and attribute directives?
+ Structural ones add or remove elements; attribute ones change an element
- Structural ones change styles; attribute ones add or remove elements
- Structural ones work on components; attribute ones on plain HTML
- Structural ones run once; attribute ones run on every change check
= *ngIf is structural; ngClass is an attribute directive.

Q M Why is track important in @for?
+ It lets Angular reuse DOM for items it has seen before
- It sorts the list by the tracked property before rendering
- It removes duplicate items that share the same tracked value
- It turns on two-way binding for every item in the loop
= Use a unique id; trackBy did the same for *ngFor.

Q M What does @empty do inside an @for block?
+ Shows its content when the list has no items
- Removes empty strings and nulls from the list
- Shows its content after the last item of the list
- Clears the list when the component is destroyed
= e.g. @for (...) { ... } @empty { <p>No jobs</p> }.

Q M What is a pure pipe?
+ A pipe that reruns only when its input reference changes
- A pipe that has no parameters and no dependencies
- A pipe that runs on every change detection pass
- A pipe that can only transform strings and numbers
= Pipes are pure by default, which keeps them cheap.

Q H Why does a pure pipe not update after items.push(newItem)?
+ The array reference is unchanged, so the pipe is not rerun
- push is asynchronous, so the pipe runs before the item arrives
- Pure pipes cache results permanently until the page reloads
- Arrays must be wrapped in a signal before a pipe can read them
= Create a new array (items = [...items, newItem]) or use an impure pipe sparingly.

Q H What does the async pipe do?
| {{ user$ | async }}
+ Subscribes, shows the latest value and unsubscribes on destroy
- Subscribes once and keeps the subscription open after destroy
- Converts the observable to a promise and awaits the first value
- Delays rendering of the whole template until the value arrives
= It avoids manual subscriptions and leaks.

Q H How do you build a directive that highlights an element on hover?
+ A @Directive with host listeners for mouseenter and mouseleave
- A @Pipe whose transform method returns the highlight colour
- A @Component whose template wraps the element in a span
- An @Injectable service that watches the mouse position
= Use host: { '(mouseenter)': '...' } or @HostListener.

Q H What does @defer (Angular 17+) do?
| @defer (on viewport) { <app-chart /> } @placeholder { <p>…</p> }
+ Loads the block's code when its trigger fires, e.g. on scroll
- Renders the block on the server and skips it in the browser
- Delays the whole page until the chart's data has loaded
- Retries rendering the block if it throws an error
= Angular splits that code into a separate chunk automatically.

@topic ng-services-di | FUNDAMENTALS | Services and dependency injection | Services, @Injectable, providedIn root, injector hierarchy, singletons, sharing data and logic.
Q E What is a service in Angular?
+ A class holding shared logic or data, such as API calls
- A component that has a template but no styles
- A file that lists the routes of the application
- A pipe that formats values coming from the server
= Components stay focused on the view; services hold the logic.

Q E What does providedIn: 'root' mean?
+ The whole app shares one instance
- Each component gets its own instance
- The service runs only on the server
- The service is created on every call
= It is also tree-shakable when unused.

Q E How does a component get a service?
+ Angular injects it, through the constructor or inject()
- The component creates it with new ApiService()
- The component imports it and calls it statically
- The service registers itself on the window object
= Angular creates and supplies the instance.

Q E What does @Injectable() mark?
+ A class Angular can inject and give dependencies to
- A component that can be loaded lazily by the router
- A pipe that can be used in any template of the app
- A test that runs in the browser rather than in Node
= Services are usually @Injectable({ providedIn: 'root' }).

Q M What happens if a service is listed in a component's providers array?
+ That component and its children get their own instance
- The whole application switches to that new instance
- Angular reports an error because it is already in root
- The service becomes lazy and is created on first click
= Injectors form a hierarchy; the nearest provider wins.

Q M Why use dependency injection instead of creating dependencies with new?
+ Code stays loosely coupled and is easy to test with fakes
- Objects created with new are not garbage collected
- Angular forbids using new anywhere in a component
- Injected objects run faster than objects made with new
= Tests can provide a mock in place of the real service.

Q M What is an InjectionToken used for?
+ Injecting non-class values, like configuration objects
- Signing users in and storing their access token
- Naming routes so they can be linked from templates
- Marking which components can be lazy-loaded
= e.g. { provide: API_URL, useValue: 'https://...' }.

Q M How can components share a selected job through a service?
+ The service holds it in a signal or BehaviorSubject
- Each component stores its own copy of the job
- The service stores it in a static field of a component
- The components pass it through @Output to the service
= The service is the single source of truth.

Q H What do useClass, useValue and useFactory providers give?
+ A class instance, a fixed value, or a function's result
- A singleton, a transient object, or a scoped object
- A service, a component, or a directive respectively
- A lazy value, an eager value, or a cached value
= Factories can depend on other injected values.

Q H Why might a lazy-loaded route get a different service instance than the rest of the app?
+ The service is provided in that route's own providers
- Lazy routes always duplicate every service they use
- The router clears the root injector on each navigation
- Services in lazy routes are recreated on every visit
= Use providedIn: 'root' for app-wide singletons.

Q H What does inject(X, { optional: true }) do when no provider exists?
+ Returns null instead of throwing
- Creates a default instance of X
- Throws when the component is used
- Waits until a provider is added
= Useful for optional plugins or configuration.

Q H What is multi: true used for in a provider?
+ Collecting several values for one token into an array
- Running one service on several threads at the same time
- Allowing the same component to be declared twice
- Creating a new service instance for every injection
= HTTP interceptors and app initialisers use multi providers.

@topic ng-http-rxjs | PRACTICAL | HttpClient and RxJS basics | HttpClient requests, observables and subscribing, the async pipe, common operators, error handling, interceptors.

+ An Observable of the response body
- A Promise of the response body
- The response body directly
- A callback registration id

Q E What is an Observable?
+ A stream of values you subscribe to
- A value that can never change
- A component that watches the DOM
- A list that sorts itself

Q E Which operator transforms each emitted value?

- filter
- tap
- take

Q E How do you make HttpClient available in a standalone app?

- HttpClient is global, so no setup is needed

Q M What happens if you call http.get(url) but never subscribe?
+ No request is sent
- The request is sent once
- The request is sent and cached
- An error is thrown immediately

Q M How do you handle an HTTP error in an observable chain?
+ With the catchError operator
- With try/catch around subscribe
- With the finalize operator alone
- Errors are retried automatically

Q M What is an HTTP interceptor used for?

Q M Why unsubscribe from long-lived observables in components?

- Observables stop after their first value anyway
- Unsubscribing makes HTTP requests faster
- Angular throws if a subscription stays open

Q H Two components subscribe to the same HTTP observable. How many requests are sent?

- One, because HTTP observables are shared
- None until a third component subscribes
- One per change detection pass

Q H Why does retry(3) on a POST that creates an order need care?

- Retries are sent to a different server

Q H What does toSignal(this.http.get(url)) give you?

- A promise that resolves when the request completes

Q H How do you test a service that uses HttpClient without real calls?

@topic ng-change-detection | ADVANCED | Change detection and signals | Zone.js, default vs OnPush, signals (signal, computed, effect), zoneless Angular, immutability.
Q E What does change detection do in Angular?
+ Updates the DOM when component data changes
- Recompiles the app when source files change
- Detects security problems in templates
- Tracks which files changed in git
= Traditionally Zone.js triggers it after events, timers and HTTP calls.

Q E What is a signal?
+ A reactive value that notifies readers when it changes
- An event emitted by a DOM element on click
- A message sent from a service to the server
- A route event fired after navigation ends
= count = signal(0); read count(), change with set() or update().

Q E What does computed() create?
+ A read-only signal derived from other signals
- A writable signal with a default value
- A function that runs once at start-up
- A pipe that formats a signal's value
= total = computed(() => price() * qty()).

Q E With ChangeDetectionStrategy.OnPush, when is a component checked?
+ When its inputs change, it handles an event, or a signal it reads changes
- On every change detection pass, like the default strategy
- Only when you call ChangeDetectorRef.detectChanges() manually
- Only once, when the component is first created
= It reduces work in large apps.

Q M With OnPush, why does this not update the child?
| this.user.name = "New";   // parent changes the object passed as [user]
+ The input reference did not change, so the child is skipped
- OnPush blocks every update until the page reloads
- Objects cannot be passed as inputs to OnPush children
- name is read-only on objects passed through inputs
= Pass a new object: this.user = { ...this.user, name: "New" }.

Q M What does effect() do?
+ Runs code whenever the signals it reads change
- Derives a new read-only value from other signals
- Runs code once when the component is destroyed
- Batches HTTP calls made inside the component
= Use it for side effects (logging, storage), not for deriving state.

Q M With Zone.js, what triggers change detection?
+ Async events such as clicks, timers and HTTP responses
- Only explicit calls to detectChanges()
- Only route changes and form submissions
- A timer that runs every 100 milliseconds
= Zone.js patches browser APIs to know when to check.

Q M Why update array signals immutably?
| items.update(list => [...list, newItem]);
+ A new reference makes readers reliably see the change
- Signals cannot store arrays that are mutated
- It makes the array use less memory
- It turns off change detection for the list
= Mutating the same array in place may not notify readers.

Q H What does zoneless Angular rely on instead of Zone.js?
+ Signals and other explicit notifications
- Polling the component tree every frame
- Web workers watching the DOM for changes
- A full page reload after each event
= Enabled with provideZonelessChangeDetection().

Q H What does ExpressionChangedAfterItHasBeenCheckedError mean?
+ A bound value changed in the same pass after it was checked
- A template expression has a syntax error
- An HTTP response arrived after the component was destroyed
- A child component was checked twice in one pass
= Often caused by changing parent state in a child's ngAfterViewInit (dev mode check).
